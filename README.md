# Конструктор Telegram-ботов

Главный бот позволяет владельцу добавлять зеркальные боты по токену BotFather, назначать им владельцев и включать или выключать их. Каждый владелец настраивает только свой бот через `/admin`.

## Запуск

1. Установите Python 3.12 или новее.
2. Создайте виртуальное окружение: `py -3.12 -m venv .venv`.
3. Активируйте его: `.\.venv\Scripts\Activate.ps1`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Скопируйте `.env.example` в `.env`.
6. В `BOT_TOKEN` вставьте токен главного управляющего бота из `@BotFather`.
7. В `ADMIN_ID` вставьте ваш числовой Telegram ID. Его можно узнать через бота вроде `@userinfobot`.
8. Запустите: `python -m bot.app`.

## Использование

1. Откройте главный бот и отправьте `/admin`.
2. Нажмите «Добавить зеркало».
3. Вставьте токен бота-зеркала из `@BotFather`.
4. Введите числовой Telegram ID владельца этого зеркала.
5. Владелец открывает свой бот и отправляет `/admin`.
6. В панели владельца создайте главный раздел, затем кнопки `text`, `url` или `submenu`.

В главной панели «Мои зеркала» можно остановить или снова запустить любое зеркало. При остановке настройки не удаляются.

## VPS позже

На Ubuntu скопируйте проект, создайте `.env`, установите зависимости в виртуальное окружение и запускайте `python -m bot.app` через `systemd`. Базу `data/bot.db` храните с правами доступа только для пользователя, запускающего сервис: в ней находятся токены зеркал.

## Безопасность

- Не отправляйте токены в публичные чаты и не добавляйте `.env` или `data/bot.db` в Git.
- Пользователь, которому назначен Telegram ID, получает полный доступ к настройкам своего зеркала.
- Удаление зеркала удаляет его настройки из базы, но не удаляет самого бота у Telegram. Для этого используйте `@BotFather`.
